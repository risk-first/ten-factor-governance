# Markdown Viewer

Front-end FDC3 **data app** (no backend) that renders [`fdc3.data.markdown`](../../fdc3-extensions/fdc3.data/schemas/markdown.schema.json).

| Mechanism | Behaviour |
| --- | --- |
| `fdc3.open` with `fdc3.data.markdown` | Seed display |
| `ViewData` + `fdc3.data.markdown` | Replace-in-place |

Port **4108** (`aipa-markdown-viewer`).
