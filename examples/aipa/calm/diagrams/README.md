# Generated CALM diagrams

Do not edit these files by hand. Regenerate from `../architecture.json` and
`../templates/diagrams.md`:

```bash
npm run calm:diagrams
```

That writes Mermaid (`.mmd`) here and SVGs to
`static/img/calm/ai-portfolio-assistant/`. The SVGs are committed so the
Docusaurus site build can resolve `/img/calm/...` image links in CI.
