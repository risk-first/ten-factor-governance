# Generated CALM diagrams

Do not edit these files by hand. Contents of this folder (except this README)
are gitignored. Regenerate from `../architecture.json` and
`../templates/diagrams.md`:

```bash
npm run calm:diagrams
```

That writes Mermaid (`.mmd`) here and SVGs to
`static/img/calm/ai-portfolio-assistant/` (also gitignored).
