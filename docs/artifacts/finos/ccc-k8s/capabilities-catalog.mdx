# CCC Kubernetes Capabilities Catalog

This page renders the FINOS Common Cloud Controls Managed Kubernetes capabilities
as a [Gemara](/docs/artifacts/gemara) `CapabilityCatalog`, including the shared
CCC Core capabilities this service catalog imports. Native K8S entries and
imported Core entries appear together, grouped by capability domain.

For the companion catalogs, see the
[Threats Catalog](./threats-catalog) and
[Controls Catalog](./controls-catalog).
