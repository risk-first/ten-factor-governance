# CCC Kubernetes Threats Catalog

This page renders the FINOS Common Cloud Controls Managed Kubernetes threats as a
[Gemara](/docs/artifacts/gemara) `ThreatCatalog`. It includes shared CCC Core
threats this service imports, plus CWE and MITRE ATT&CK mappings shown on each
matching threat.

For the companion catalogs, see the
[Capabilities Catalog](./capabilities-catalog) and
[Controls Catalog](./controls-catalog).

  file={k8sThreats}
  resolve={{'CCC.Core.Threats': coreThreats}}

/>
