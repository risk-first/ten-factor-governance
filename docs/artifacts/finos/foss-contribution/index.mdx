# FOSS Contribution

Machine-readable governance for employee contribution to Free and Open Source
Software, expressed with the [Gemara](/docs/artifacts/gemara) model. Based on
FINOS'
[Open Source Readiness Reference FOSS Policy](https://osr.finos.org/docs/bok/Artifacts/Reference-FOSS-Policy).

## How the artifacts connect

```mermaid
flowchart LR
  Lexicon -->|terms for| Principles
  Lexicon -->|terms for| Guidance
  Principles -->|orient| Guidance
  Vectors -->|cited by| Guidance
  Vectors -->|attack path for| Threats
  Capabilities -->|enable| Threats

  Guidance -->|implemented by| Controls
  Threats -->|mitigated by| Controls
  Threats -->|materialise as| Risks

  Controls -->|imported by| Policy
  Risks -->|mitigated by| Policy
  Guidance -->|informs| Policy

  Policy -->|governs| SensitiveActivity["Sensitive Activity"]
  SensitiveActivity -->|inspected by| EvaluationLog["Evaluation Log"]
  EvaluationLog -->|justifies| EnforcementLog["Enforcement Log"]
```
