# AI Portfolio Assistant Deployment

Deployment topology for the AI Portfolio Assistant. The authoritative
machine-readable model is
[`examples/aipa/calm/architecture.json`](https://github.com/finos/ten-factor-governance/blob/main/examples/aipa/calm/architecture.json)
(`deployed-in` / `composed-of` relationships under the banking-firewall
boundary). Diagrams below are generated from that model
(`npm run calm:diagrams`).

Logical interaction flows (FDC3 intents and governed chat) live on
[Architecture](./architecture).

## Why chat also goes through governance

The AI Portfolio Assistant **is** the chat harness. Chat turns and model
prompts/completions are still firewalled at the Governance Gateway
([AIGF AIR-PREV-003](../ai-governance/guidance-catalog),
[CCC.MARefArc.CN02](https://ccc.finos.org/catalogs/ai-ml/multi-agent-refarch)) —
see [Architecture](./architecture).

## Diagram

CALM block architecture with Managed Kubernetes hosts, Artifact Repository,

## In-firewall inference flow

Model prompts and completions leave the assistant only via Governance Gateway
LLM-egress guardrails and stay inside the banking firewall
(`flow-in-firewall-inference`).

![CALM in-firewall inference flow](/img/calm/ai-portfolio-assistant/in-firewall-inference-flow.svg)

## Key

| Component | Purpose | Governance twin / CALM node |
| --- | --- | --- |
| **Portfolio Manager** | Human user of the desktop. Retains authority for recommendations that require approval and for any path toward order proposal or execution. | `portfolio-manager` |
| **Portfolio Assistant Deployment (Managed Kubernetes)** | Hosts the AI Portfolio Assistant workload inside the banking firewall. | `aipa-k8s` · [CCC Managed Kubernetes](https://ccc.finos.org/catalogs/orchestration/k8s) |
| **AI Portfolio Assistant** | Chat harness + governed AI service. Combines deterministic app results with model interpretation; chat turns and model I/O go through the Governance Gateway. Does not perform financial calculations itself. | `ai-portfolio-assistant` · [AI Portfolio Assistant](./gemara/components/ai-portfolio-assistant/) |
| **Governance Runtime Deployment (Managed Kubernetes)** | Hosts the Portfolio Assistant Governance Runtime as a separate Kubernetes deployment. | `governance-runtime-k8s` · [CCC Managed Kubernetes](https://ccc.finos.org/catalogs/orchestration/k8s) |
| **Governance Runtime / Gateway** | Evaluates FDC3 intents, chat ingress and LLM egress (ALLOW / DENY / REQUIRE APPROVAL) and records evidence. | `governance-runtime` / `governance-gateway` · [Governance Runtime](./gemara/components/governance-runtime/) |
| **Artifact Repository (Governance Model)** | Hosts and serves versioned Governance Model releases (lexicon → policy) and the AIMS envelope. | `artifact-repository` · [Artifact Repository](./gemara/components/artifact-repository/) |
| **Records Deployment (Decisions and Evidence Record)** | Object-storage bucket for evaluation and enforcement evidence. | `evidence-record` · [CCC Object Storage](../ccc-obj-stor/) |
| **FDC3 Desktop Agent** | Interoperability layer for context and intents; calls the Governance Runtime before forwarding sensitive requests. | `fdc3-desktop-agent` |
| **Agentic Model** | Foundation-model inference **inside** the banking firewall. Prompts and portfolio context do not egress to the model supplier (`fm-no-train-on-prompts` / `apa-ctl-014`). | `agentic-model` |
| **Inside Banking Firewall** | Trust boundary for portfolio data, desktop applications, assistant runtime and model inference. | `banking-firewall` |
