
# Catalog of FDC3 operations

## Intents

### Raised by The AI Portfolio Assistant 

(for the purposes of the use case)

| Intent raised by AI Assistant | Responding app          | Input context                                                | Returned context             | Use in demo                                                                                                                                       |
| ----------------------------- | ----------------------- | ------------------------------------------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `demo.GetPortfolioRisk`      | Risk App                | `fdc3.portfolio`                                             | `demo.portfolioRisk`        | **Analyse:** “What are the biggest risks in this portfolio?” Gets deterministic risk/exposure calculations.                                       |
| `demo.GetResearch`           | Research App            | `fdc3.instrument`, `fdc3.instrumentList` or `fdc3.portfolio` | `demo.researchBundle`       | **Explain:** Gets research/evidence needed to explain the identified risks.                                                                       |
| `demo.RunStressScenario`     | Risk App                | `demo.stressScenarioRequest`                                | `demo.stressScenarioResult` | **Analyse:** Runs scenarios such as an oil-price fall or interest-rate shock.                                                                     |
| `demo.CreateOrderProposal`   | Order Entry             | `demo.portfolioRecommendation`                              | `demo.orderProposal`        | **Propose:** “Reduce my energy exposure to 15%.” Creates a draft basket for human review.                                                         |
| `demo.SubmitOrders`          | Execution / Order Entry | `fdc3.orderList`                                             | `fdc3.transactionResult`     | **Execute:** “Just execute those trades.” This is the critical intent that **governance prevents the AI Assistant from successfully exercising**. |

## Contexts

### Standard Ones We Should Broadcast / Receive 

| Context               | Typical broadcaster(s)                 | Typical receiver(s)                       | Why broadcast it                                                                       |
| --------------------- | -------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------- |
| `fdc3.portfolio`      | Portfolio App                          | Risk, Research, AI Assistant, Order Entry | Keeps the desktop aligned on the active portfolio.                                     |
| `fdc3.instrument`     | Portfolio, Risk, Research, Order Entry | Any of the other apps                     | Core desktop synchronization when the user selects a particular security.              |
| `fdc3.position`       | Portfolio, Risk                        | Risk, Research, AI Assistant, Order Entry | Carries the selected holding, not just the underlying instrument.                      |
| `fdc3.instrumentList` | Portfolio, Risk, Research              | Risk, Research, AI Assistant              | Useful when the user selects a basket, sector, top contributors, etc.                  |
| `fdc3.organization`   | Research, Portfolio                    | Research, AI Assistant                    | Useful where the workflow is about the issuer/company rather than a specific security. |
| `fdc3.order`          | Order Entry / Blotter                  | Portfolio, Risk, AI Assistant             | Lets other apps follow a selected order. Currently experimental.                       |
| `fdc3.orderList`      | Order Entry / Blotter                  | Portfolio, Risk, AI Assistant             | Useful when a basket of orders is selected. Currently experimental.                    |
| `fdc3.trade`          | Blotter / execution app                | Portfolio, Risk, AI Assistant             | Lets apps synchronize around an executed trade. Currently experimental.                |
| `fdc3.tradeList`      | Blotter / execution app                | Portfolio, Risk, AI Assistant             | Same for a group of executed trades. Currently experimental.                           |

### Ones Defined By This App suite

| FINOS context                   | Description                                                                                                                                                                                                                                                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `demo.portfolioRisk`           | **Structured risk analysis for a portfolio.** Contains calculated risk measures such as concentration, exposures, major risk contributors and other portfolio-level metrics, together with enough provenance to identify the portfolio and analysis that produced them. Returned by `demo.GetPortfolioRisk`.            |
| `demo.researchBundle`          | **A collection of research material relevant to a portfolio or set of instruments.** Contains structured research findings and references to their underlying sources, including provenance and timestamps so the Assistant can reason about the quality and freshness of its evidence. Returned by `demo.GetResearch`. |
| `demo.stressScenarioRequest`   | **A request to evaluate a portfolio under a specified hypothetical scenario.** Identifies the portfolio and describes the market changes or assumptions to apply, such as an oil-price fall, interest-rate increase or equity-market shock. Supplied to `demo.RunStressScenario`.                                       |
| `demo.stressScenarioResult`    | **The calculated effect of a stress scenario on a portfolio.** Identifies the scenario and portfolio and contains the resulting changes in portfolio value, exposures or other relevant risk measures. Returned by `demo.RunStressScenario`.                                                                            |
| `demo.portfolioRecommendation` | **A proposed change to a portfolio generated by the AI Assistant.** Describes the recommended portfolio changes, their rationale and the evidence/analysis supporting them. It is a recommendation rather than an executable order. Supplied to `demo.CreateOrderProposal`.                                             |
| `demo.orderProposal`           | **A proposed set of orders derived from a portfolio recommendation.** Represents a draft transaction that can be presented to a human for review before becoming actual orders. Returned by `demo.CreateOrderProposal`.                                                                                                 |

### FDC3 Security

When using the following contexts, we should broadcast signatures using FDC3 Security to ensure provenance:

 - `demo.portfolioRisk`
 - `demo.researchBundle`
 - `demo.stressScenarioResult`
 - `demo.portfolioRecommendation`
 - `demo.orderProposal`
