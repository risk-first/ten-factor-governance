# AI Portfolio Assistant Demo

Steps 1–7a run **without** the governance gateway. Step 7a is the failure:
an agent-initiated order reaches Execution. Step 7b turns governance on and
shows approvals.

1. **Select a portfolio** (`observe`)
   - The Portfolio app shares the selected book, or the Assistant asks for
     the current portfolio.
   - The Assistant receives the book and aligns with the desktop.

2. **Analyse portfolio risk** (`analyse`)
   - The user asks: *“What are the biggest risks in this portfolio?”*
   - The Assistant asks the Risk app for an analysis of the selected book.
   - The Risk app returns a signed risk result.
   - Optionally, the user asks for a stress test; the Assistant sends a
     scenario request and receives a signed stress result.
   - Optionally, Risk pulls price history for the instruments in focus.

3. **Gather evidence and explain** (`explain`)
   - The Assistant asks the Research app for material on the instruments or
     book in focus.
   - The Research app returns a signed research bundle.
   - The Assistant explains the book using the risk result and the research.
   - Optionally, specialist UIs open for analysis, news, instruments,
     charts, or holdings.

4. **Request an investment recommendation** (`recommend`)
   - The user asks: *“What should I do about the energy concentration?”*
   - The Assistant produces an on-screen recommendation — rationale and
     evidence, not an executable order.

5. **Create an order** (`propose`)
   - The user says: *“Reduce my energy exposure to 15%.”*
   - The Assistant asks Order Entry to draft the order or basket.
   - Order Entry returns a signed blotter draft.

6. **Human review in Order Entry**
   - The draft is shown on the blotter.
   - The user inspects the legs. This is local blotter review, not an
     independent approval workflow.

7a. **Execute without governance** (the failure)
   - The user (or the Assistant under pressure) says: *“Just execute those
     trades.”*
   - The Assistant — or Order Entry on its behalf — submits the reviewed
     draft to Execution.
   - There is no governance gateway. Execution fills and returns a signed
     result. The live portfolio updates.
   - **That is the failure.** An agent-initiated order reached the market
     with no independent approval.

7b. **Turn governance on — ask for approval**
   - Repeat the same execute attempt. The desktop now consults the
     Governance Runtime before forwarding a submit.
   - Order Entry requests approval for the action of submitting the
     reviewed draft. The Assistant must not submit the order itself.
   - An authorised reviewer opens the approval and approves or rejects.
     The AI cannot record that decision. The raising app can poll for the
     latest state.
   - On approval, the approving application performs the submit (signed as
     itself) and forwards Execution's result. A reject or cancel returns an
     error and does not fill.
   - That is the authority progression in one place:
     `observe → analyse → explain → recommend → propose` is ungated;
     `execute` requires a recorded human approval. Ten-Factor governance
     decides how far the AI may go, from explicit, machine-readable
     rules.

8. **Inspect the governance decision** (after 7b)
   - The Governance app shows the attributable trace: activity, actor,
     controls, evidence, outcome, and any required human action.
   - Contrast 7a (ungated submit) with 7b (approval then submit) to show
     that governance changes behaviour, not only records it.

9. **Connect the runtime decision to ISO 42001**
   - Walk from ISO 42001 guidance through the risk, the controls, the
     sensitive activity, the evaluation, the evidence, and the runtime
     decision.

10. **Opportunities for further expansion**
    - Here we are showing how governance can constrain an AI application
      regardless of the integration technology underneath.
    - The same gateway could apply to other tool or protocol surfaces.
    - The governance runtime itself could be an agent that observes and
      constrains the assistant.
