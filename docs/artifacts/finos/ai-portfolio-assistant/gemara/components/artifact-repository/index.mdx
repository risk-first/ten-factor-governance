# Artifact Repository Twin

Deployment home for the shared Governance Model on the
[deployment](../../../deployment) diagram. This twin covers **repository
posture** (publish, version, serve, inventory). The catalogs themselves —
lexicon through policy — live at the [Gemara root](../../) and apply across all
component twins. AIMS remains under [iso/](../../../iso/aims).

The [Governance Runtime](../governance-runtime/) is informed by model releases
served from this repository.
