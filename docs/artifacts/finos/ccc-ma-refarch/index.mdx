# CCC Multi-Agent Reference Architecture

[FINOS Common Cloud Controls](https://www.finos.org/projects/common-cloud-controls)
publishes a [Multi-Agent Reference Architecture](https://ccc.finos.org/catalogs/ai-ml/multi-agent-refarch)
covering user interaction, agent gateway, agent runtime, knowledge, LLM, MCP,
evaluation, and observability layers.

This section renders those catalogs as Gemara artifacts sourced from
`src/data/governance/finos/ccc-ma-refarch/` (upstream CCC
`catalogs/ai-ml/multi-agent-refarch`). The AI Portfolio Assistant example
imports a subset of these capabilities and controls into its app twin rather
than re-authoring the architecture catalog.
