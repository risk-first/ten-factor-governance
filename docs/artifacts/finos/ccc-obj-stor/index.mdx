# FINOS CCC Object Storage

[FINOS Common Cloud Controls](https://www.finos.org/projects/common-cloud-controls)
defines shared security capabilities, threats, and controls for cloud services.
This section renders the
[Object Storage](https://ccc.finos.org/catalogs/storage/object) service catalogs
as Gemara artifacts. Each catalog inlines the CCC Core entries it imports.

The catalogs are sourced from `src/data/governance/finos/ccc-object-storage/`
(plus Core YAML under `ccc-core/`) and rendered for browsing and reuse in
downstream governance content such as the AI Portfolio Assistant example.
