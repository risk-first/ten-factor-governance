<Purpose>

Planned internal audit of the AIMS: scope, cadence, auditor independence, schedule and follow-up.

</Purpose>

<Role>

ISO/IEC 42001 Clause 9.2 requires an internal audit programme. Gemara [Audit Log](/docs/artifacts/definitions/assure/audit-log) records an audit that happened; this artefact is the programme that plans, staffs and follows those audits. The ISO/IEC 27001 analysis treated the same gap as extra fields on Audit Log rather than a separate type.

This page is a stub: fields, examples and schema are still to be specified.

</Role>
