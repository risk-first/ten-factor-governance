# Definitions

Every governance artifact this site describes, in one catalogue. An artifact has
one page however you arrive at it: the title is the name used here, and the
header lists the names [Gemara](/docs/artifacts/gemara),
[ISO/IEC 27001](/docs/artifacts/iso-iec/iso27001) and
[ISO/IEC 42001](/docs/artifacts/iso-iec/iso42001) give it. Those three pages are views
onto this same set, in each standard's own vocabulary.

As discussed in the [Governance Twin Factor](/docs/factors/build-a-governance-twin),
your governance definitions should be created as a set of structured entities,
managed alongside the sensitive activity in question. For machine-readable
shapes, see the [Gemara schemas](https://gemara.openssf.org/schema/).
