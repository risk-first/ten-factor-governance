<GovernanceArtifact>

<Purpose>

Internal and external issues, objectives and jurisdictions that frame the ISMS or AIMS.

</Purpose>

<Role>

ISO/IEC 27001 Clause 4.1 and ISO/IEC 42001 Clause 4.1 both expect the organisation to determine issues relevant to its purpose and to the intended outcomes of the management system. This artefact is that organisation-level context record—not the runtime context of a single decision.

This page is a stub: fields, examples and schema are still to be specified.

</Role>
