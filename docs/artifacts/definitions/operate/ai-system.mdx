<Purpose>

The AI system being governed: purpose, limitations, versions, interfaces and links to system/model cards.

</Purpose>

<Role>

ISO/IEC 42001 Annex A.6 expects the organisation to identify AI systems and retain information about purpose, limitations, human oversight and expected user behaviour. Ten Factor governs the *activity* the system performs; this artefact names the system those activities run, with references to external Model Cards, System Cards, architecture (for example CALM) and development records. It is an ISO/IEC 42001 specialisation of [Governed Resource](/docs/artifacts/definitions/operate/governed-resource).

This page is a stub: fields, examples and schema are still to be specified.

</Role>
