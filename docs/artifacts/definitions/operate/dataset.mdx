<Purpose>

A data resource used by an AI system, with ownership, purpose, sensitivity, rights, provenance and quality.

</Purpose>

<Role>

ISO/IEC 42001 Annex A.7 expects data resources for AI to be identified, with lifecycle purpose, allowed uses and quality. This is an AI-specific specialisation of [Governed Resource](/docs/artifacts/definitions/operate/governed-resource).

This page is a stub: fields, examples and schema are still to be specified.

</Role>
