<GovernanceArtifact>

<Purpose>

A security or AI event the management system must classify, decide on, communicate and learn from.

</Purpose>

<Role>

ISO/IEC 27001 Annex A and ISO/IEC 42001 expect incidents to be handled and, where required, communicated to affected stakeholders. Evaluation and enforcement logs record governance decisions; they are not an incident case file.

This page is a stub: fields, examples and schema are still to be specified.

</Role>
