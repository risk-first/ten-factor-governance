<GovernanceArtifact>

<Purpose>

An asset, system, facility, service or process the ISMS governs, with classification and ownership.

</Purpose>

<Role>

ISO/IEC 27001 Annex A (inventory, acceptable use, classification, suppliers) assumes a catalogue of information assets and related resources. Ten Factor governs *activities*; this artefact names the resources those activities run on or produce. ISO/IEC 42001 specialises the same concern into [AI System](/docs/artifacts/definitions/operate/ai-system), [Dataset](/docs/artifacts/definitions/operate/dataset) and [Tool Resource](/docs/artifacts/definitions/operate/tool-resource) rather than a single resource type.

This page is a stub: fields, examples and schema are still to be specified.

</Role>
