# Ten Factor Governance

Docusaurus site for **Ten Factor Governance** — a methodology for building
systems that stay compliant, manage risk, survive audits, and demonstrate care
for the organisational goals society places on firms.

Visit: https://tenfactorgovernance.org

## Examples

Runnable demos that show Ten Factor Governance patterns in practice live under
[`examples/`](./examples/).

- **[AIPA (AI Portfolio Assistant)](./examples/aipa/README.md)** — FDC3 specialist
  apps (portfolio, risk, research, market data, order entry, execution) plus a
  combined app directory for agents such as Sail. See that README for setup,
  ports, and API keys.
