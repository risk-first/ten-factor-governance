apa-controls 
- id: apa-ctl-005-propose-human-approval
  title: First Human Approval for
    Agent-Initiated Orders
  objective: >
    Require a recorded first human approval
    before any agent-initiated order can
    be executed.
  group: oversight
  state: Active
  assessment-requirements:
    - id: apa-ctl-005-propose-human-approval.ar01
      text: >
        An agent-initiated path toward
        execution MUST request human
        approval for the action to perform.
        The approving application MUST
        record a first authorised human
        decision before performing that
        action. The assistant MUST NOT
        submit the order itself. Missing
        approval, AI self-approval, or an
        unauthenticated identity is a
        control failure. In the AIPA
        example this is assessed on
        demo.SubmitOrder: Passed only when
        the raise is from a trusted
        approving application or signed
        with that application's JWKS;
        otherwise Needs Review and
        GetApproval.
continued 
      applicability:
        - propose
        - execute
        - human-approval-required
      recommendation: >
        Correlate order-construction and
        approval events with approval
        records; treat assistant-originated
        submits, missing approver identity,
        or self-approval as failures. In
        the example, inspect raise identity
        and attestation on demo.SubmitOrder.
      state: Active
  guidelines:
    - reference-id: apa-guidance
      entries:

        - reference-id: apa-guidance-tool-allowlist
    - reference-id: FINOS-AIR
      entries:
        - reference-id: AIR-PREV-018

        - reference-id: AIR-DET-011
        - reference-id: AIR-DET-021
