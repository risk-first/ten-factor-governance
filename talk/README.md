# AI Governance With FDC3 and Fluxnova

Standalone HTML slides for the talk. Open [`index.html`](index.html) in a browser, or open any slide folder directly.

## How to present

- Each slide is a 16:9 HTML page in its own folder.
- Use `←` / `→`, `Page Up` / `Page Down`, or Space to move between slides.
- Speaker notes live beside each slide as `notes.md`. They are not shown on screen.

## Layout

```
talk/
  index.html
  css/talk.css
  js/talk.js
  00-title/index.html
  00-title/notes.md
  ...
```

No build step. Shared styles are in [`css/talk.css`](css/talk.css).

## Editing

- Fill in speaker, event and date on the title slide (`00-title/index.html`).
- Citations use the shared `.cite` footer. Add one only when a source exists.
- Drop images into the slide folder that uses them.
